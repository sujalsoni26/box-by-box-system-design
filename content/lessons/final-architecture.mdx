## Read it top to bottom

<Steps>

1. DNS finds the gateway (see [DNS](/learn/foundations/dns)).
2. Static files come from the CDN, backed by object storage (see [CDN](/learn/scaling/cdn) and [Object storage](/learn/data/object-storage)).
3. API calls pass the gateway (TLS, auth, rate limits) to stateless services (see [Monolith vs microservices](/learn/communication/microservices) and [Rate limiting](/learn/reliability/rate-limiting)).
4. Services read the cache before the database (see [Caching](/learn/reliability/caching)).
5. Slow side effects go onto queues for workers (see [Message queues](/learn/reliability/message-queues)).

</Steps>

Timeouts, backoff, circuit breakers and idempotency keys guard every call (see [Performance and Reliability](/learn#reliability)).

<Callout type="idea" title="Key takeaway">

Every component adds complexity and cost. Add one only when its problem appears, and in interviews <mark>justify each box by the problem it solves</mark>.

</Callout>
